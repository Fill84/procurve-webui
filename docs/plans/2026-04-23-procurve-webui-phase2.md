# procurve-webui — Phase 2 (Docker + read-only UI) Implementation Plan

>
> **Prerequisite:** Phase 1 complete (tag `phase1-complete`). The `procurve_client` Python package is shipped and all operations are tested.

**Goal:** Build a single-container Docker deployment with a FastAPI backend that serves a React SPA. Ship the Identity + Status + Backups tabs as fully working read-only views. Configuration / Security / Diagnostics / Support tabs appear in the nav but show "coming in a later phase" placeholders.

**Architecture:** Uvicorn runs FastAPI; FastAPI exposes `/api/v1/*` REST + `/ws/*` WebSocket and serves the pre-built React `dist/` bundle from `/`. User logs in with switch credentials; backend validates against the live switch, issues a signed session cookie, and holds a `ProcurveTransport` in memory keyed by session id. All switch calls flow through the authenticated transport.

**Tech Stack:**
- Backend: Python 3.12, FastAPI, uvicorn, httpx (already via procurve_client), itsdangerous (session signing), structlog.
- Frontend: TypeScript, React 18, Vite, TailwindCSS v4, shadcn/ui, TanStack Query, TanStack Router, Zod (via openapi-typescript), Recharts.
- Packaging: Docker multi-stage (node → python-slim).

**Spec references:**
- Design: `docs/specs/2026-04-23-procurve-webui-design.md` — §2 architecture, §9 frontend, §10 Docker, §11.3 auth.
- Prior plans: `phase0-plan.md`, `phase1-plan.md`.
- Library: `backend/procurve_client/`.

**Safety constraints (from memory):** Phase 2 is read-only from a switch standpoint. Live switch writes remain ONLY through the existing `upload_config` path (user-driven) and no new write-test sessions are allowed without explicit approval. The end-user UI's Backups tab provides `[Download .pcc]` and `[Restore…]` actions; the restore action calls the `@WRITE upload_config` and will be blocked by `READ_ONLY=true` in the default docker image — users must flip `READ_ONLY=false` in `.env` to enable it.

```python
"""Application settings loaded from environment variables."""
from __future__ import annotations

from pydantic import Field, field_validator
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    """All runtime configuration. Values come from `.env` or OS env."""

    model_config = SettingsConfigDict(env_file=".env", env_file_encoding="utf-8", case_sensitive=False)

    switch_host: str = Field(..., description="IP or hostname of the ProCurve switch")
    switch_port: int = Field(default=80)
    host: str = Field(default="127.0.0.1", description="Bind address for the UI")
    port: int = Field(default=8080)
    read_only: bool = Field(default=True)
    poll_interval_seconds: float = Field(default=2.0)
    session_secret: str = Field(..., min_length=32, description="Random signing key")
    session_ttl_hours: int = Field(default=8, gt=0)
    metrics_enabled: bool = Field(default=False)

    @field_validator("session_secret")
    @classmethod
    def _reject_placeholder(cls, v: str) -> str:
        if v.strip() in {"", "change-me", "your-secret-here"}:
            raise ValueError("SESSION_SECRET must be a real random value")
        return v
```

- [ ] **Step 5: Implement `errors.py`**

Maps `procurve_client` exceptions to HTTP responses. Follow the design spec §11.1 table.

```python
"""Map procurve_client exceptions to HTTP responses."""
from __future__ import annotations

from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

from procurve_client.errors import (
    AuthError,
    OperationError,
    ProtocolError,
    TransportError,
    WriteDisabledError,
)


def install_error_handlers(app: FastAPI) -> None:
    @app.exception_handler(TransportError)
    async def _transport(request: Request, exc: TransportError) -> JSONResponse:
        return JSONResponse(status_code=502, content={"error": "transport", "detail": str(exc)})

    @app.exception_handler(AuthError)
    async def _auth(request: Request, exc: AuthError) -> JSONResponse:
        return JSONResponse(status_code=401, content={"error": "auth", "detail": str(exc)})

    @app.exception_handler(ProtocolError)
    async def _protocol(request: Request, exc: ProtocolError) -> JSONResponse:
        return JSONResponse(status_code=500, content={"error": "protocol", "detail": str(exc)})

    @app.exception_handler(OperationError)
    async def _operation(request: Request, exc: OperationError) -> JSONResponse:
        return JSONResponse(status_code=422, content={"error": "operation", "detail": str(exc)})

    @app.exception_handler(WriteDisabledError)
    async def _write_disabled(request: Request, exc: WriteDisabledError) -> JSONResponse:
        return JSONResponse(status_code=403, content={"error": "read_only", "detail": str(exc)})
```

```python
"""FastAPI application factory."""
from __future__ import annotations

from contextlib import asynccontextmanager
from collections.abc import AsyncIterator

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

from app.errors import install_error_handlers
from app.logging_config import configure_logging
from app.settings import Settings


@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    configure_logging()
    app.state.settings = Settings()
    yield


def create_app() -> FastAPI:
    app = FastAPI(title="procurve-webui", version="0.1.0", lifespan=lifespan)
    app.add_middleware(
        CORSMiddleware,
        allow_origins=[],
        allow_credentials=True,
        allow_methods=["GET", "POST", "DELETE"],
        allow_headers=["*"],
    )
    install_error_handlers(app)
    return app


app = create_app()
```

## Task 2.2: Session auth + transport cache

**Files:**
- Create: `backend/app/auth.py`
- Create: `backend/app/api/__init__.py`
- Create: `backend/app/api/auth.py`
- Create: `backend/app/deps.py`
- Create: `backend/tests/app/test_auth_flow.py`

Auth model (from spec §11.3):
- POST `/api/v1/auth/login` with `{username, password}` → backend tests credentials against switch by attempting a known-good read (`download_config` is the canonical probe; returns 401 on bad creds via `AuthError`). On success, generates session id, signs with itsdangerous, sets `session` cookie (HttpOnly, SameSite=Strict), caches `ProcurveTransport` under session id. Returns `{session_id, expires_at}`.
- POST `/api/v1/auth/logout` → clears session-id entry, deletes cookie.
- GET `/api/v1/auth/whoami` → returns `{username, expires_at}` if session valid, 401 otherwise.

Session store is in-memory (`dict[str, SessionEntry]`). No persistence — restart forces re-login (spec says this is acceptable).

Write failing tests first (use respx to mock the switch credential probe), implement, commit.

Key test cases:
- `test_login_with_blank_creds_succeeds_when_switch_accepts_blank` — current switch state.
- `test_login_with_wrong_creds_returns_401` — switch returns 401.
- `test_logout_clears_session` — subsequent requests get 401.
- `test_whoami_returns_username_when_authenticated`.
- `test_whoami_401_when_no_cookie`.
- `test_session_expires_after_ttl` — use monkeypatch on clock helper.

`deps.py` provides:
- `get_session(request: Request) -> SessionEntry` — raises HTTPException 401 if missing/invalid.
- `get_transport(session: SessionEntry = Depends(get_session)) -> ProcurveTransport` — returns the cached transport.

## Task 2.4: Backups API (download + list local backups + restore)

**Files:**
- Create: `backend/app/api/backups.py`
- Create: `backend/app/backup_store.py` — filesystem-backed store under `/app/backups` (or configurable path)
- Create: `backend/tests/app/test_api_backups.py`
- Create: `backend/tests/app/test_backup_store.py`

Endpoints:
- `GET /api/v1/backups` — list all stored backups with metadata (filename, timestamp, size, sha256, trigger).
- `POST /api/v1/backups` — trigger a download-and-save. Calls `download_config` and writes to store. Returns the new backup metadata.
- `GET /api/v1/backups/live-sha` — returns SHA256 of the live config (convenience for UI diff comparison).
- `GET /api/v1/backups/{filename}/download` — streams the file to the user.
- `GET /api/v1/backups/{filename}/diff` — returns unified-diff against live (text response).
- `POST /api/v1/backups/{filename}/restore` — calls `upload_config` with the stored backup. Blocked by `READ_ONLY=true` — returns 403 with hint.
- `DELETE /api/v1/backups/{filename}` — remove from store.

`backup_store.py` API:
```python
class BackupMeta(BaseModel):
    filename: str
    created_at: datetime
    size: int
    sha256: str
    trigger: Literal["manual", "pre-write", "scheduled"]

class BackupStore:
    def __init__(self, root: Path) -> None: ...
    def list(self) -> list[BackupMeta]: ...
    def save(self, backup: ConfigBackup, trigger: str) -> BackupMeta: ...
    def load(self, filename: str) -> ConfigBackup: ...
    def delete(self, filename: str) -> None: ...
```

Metadata stored as sidecar JSON (`<filename>.meta.json`) next to the `.pcc`.

Tests use `tmp_path` fixture for the store root.

```python
# static.py
from pathlib import Path
from fastapi import FastAPI
from fastapi.responses import FileResponse
from fastapi.staticfiles import StaticFiles


def mount_static(app: FastAPI, dist_dir: Path) -> None:
    if not dist_dir.is_dir():
        # During dev the frontend may not be built yet — skip gracefully.
        return

    # Serve hashed assets under /assets with long-cache headers.
    app.mount("/assets", StaticFiles(directory=dist_dir / "assets"), name="assets")

    # Client-side routing: any unmatched GET falls through to index.html.
    @app.get("/{full_path:path}", include_in_schema=False)
    async def spa_fallback(full_path: str) -> FileResponse:
        return FileResponse(dist_dir / "index.html")
```

Mount order matters: static fallback must be last, after all `/api/v1/*` and `/ws/*` routes.

Test: assert `GET /` returns `index.html` content when `dist/` exists.

```dockerfile
# docker/Dockerfile
FROM node:22-alpine AS frontend-build
WORKDIR /app/frontend
COPY frontend/package*.json ./
RUN npm ci
COPY frontend/ .
RUN npm run build

FROM python:3.12-slim AS backend
WORKDIR /app
ENV PYTHONUNBUFFERED=1 PIP_NO_CACHE_DIR=1
RUN adduser --system --group --no-create-home appuser \
    && mkdir -p /app/backups \
    && chown appuser:appuser /app/backups
COPY backend/pyproject.toml ./backend/pyproject.toml
COPY backend/procurve_client ./backend/procurve_client
COPY backend/app ./backend/app
RUN pip install /app/backend
COPY --from=frontend-build /app/frontend/dist /app/frontend/dist
COPY docker/entrypoint.sh /app/entrypoint.sh
COPY docker/healthcheck.sh /app/healthcheck.sh
RUN chmod +x /app/entrypoint.sh /app/healthcheck.sh
USER appuser
EXPOSE 8080
HEALTHCHECK --interval=30s --timeout=10s --start-period=15s --retries=3 \
  CMD /app/healthcheck.sh
ENTRYPOINT ["/app/entrypoint.sh"]
```

`entrypoint.sh`:
```bash
#!/bin/sh
set -e
# Validate required env
: "${SWITCH_HOST:?SWITCH_HOST must be set}"
: "${SESSION_SECRET:?SESSION_SECRET must be set (generate with: python -c \"import secrets; print(secrets.token_urlsafe(32))\")}"
exec uvicorn app.main:app --app-dir /app/backend --host "${HOST:-0.0.0.0}" --port "${PORT:-8080}"
```

`healthcheck.sh`:
```bash
#!/bin/sh
```
