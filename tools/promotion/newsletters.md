# Newsletter submissions

These accept third-party project submissions without an account. Total
time to do all of them: ~15 min.

---

## Console.dev — weekly dev tools newsletter (~30k devs)

**Submit at:** https://console.dev/submit/
**Form fields they ask for:**

- **Name of tool:** `procurve-webui`
- **URL:** `https://github.com/Fill84/procurve-webui`
- **One-line description:**

  > Modern Java-applet-free web UI for the HP ProCurve 2810-24G (J9021A)
  > switch — single Docker container, talks the switch's stock eHTTP
  > protocol.

- **Why is this interesting to developers?** (paragraph)

  > A clean-room reverse-engineering of HP's defunct Java applet,
  > documented endpoint by endpoint under `research/protocol/`. Useful
  > both as a working tool (single Docker container, MIT licensed,
  > React + FastAPI) and as a reference for anyone who has to
  > reverse-engineer legacy enterprise hardware. The Python protocol
  > library is split out as a reusable, pip-installable package, so
  > the same project also functions as a programmable Python client
  > for the switch.

- **Your name / Twitter handle (optional):** Leave blank or use
  `Fill84` (your GitHub handle).

## Self-Hosted Weekly (selfh.st) — weekly self-hosted projects newsletter (~20k subs)

**Submit at:** https://selfh.st/submit/
**Format:** They have a tip form. Fill in:

- **Project name:** procurve-webui
- **Project URL:** https://github.com/Fill84/procurve-webui
- **Type:** Self-hosted application
- **Brief description:**

  > Self-hosted, Java-applet-free management UI for HP ProCurve 2810-24G
  > (J9021A) switches. One Docker container, FastAPI + React, MIT.
  > Identity / Status / Configuration / Security / Diagnostics /
  > Backups tabs all working. Read-only by default; auto-backup before
  > every write.

## Hacker Newsletter — weekly digest of best HN stories (~50k subs)

**Submit:** Email `tip@hackernewsletter.com` with the subject "Show HN
candidate: procurve-webui" and the message body:

```
Thought this might fit Hacker Newsletter. It's an open-source replacement

small reverse-engineering project that turned into a usable tool. v0.1.0
just landed.

Repo + screenshots: https://github.com/Fill84/procurve-webui

Cheers,
[your name or first name]
```

## Changelog Weekly (TheChangelog.com)

**Submit at:** https://changelog.com/submissions/news (form-based)

- **Type:** "New project" / "Open source release"
- **Title:** `procurve-webui v0.1.0 — replace your old HP switch's dead Java applet`
- **URL:** https://github.com/Fill84/procurve-webui/releases/tag/v0.1.0
- **Description:**

  > One-paragraph blurb in the same vein as Console.dev. Don't repeat
  > the literal text — Changelog editors notice cross-newsletter
  > duplicates and downrank. Rephrase to lead with "v0.1.0 first
  > release" rather than "what is it".

## Awesome Newsletters (catch-all)

**Optional but high-leverage:** Submit to https://www.awesomenewsletters.com/
in their "Open Source" category. Increases chance of pickup by smaller
niche newsletters.

---

## After submitting

- These are blind submissions; you usually don't hear back. If a
  newsletter does pick it up, you'll see the GitHub stargazer count
  jump on whatever day they send.
- One submission per newsletter. If they ignore the first, don't
  resubmit unless v0.2.0+ has substantively new content.
